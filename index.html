Rest timer alerts

Alert with iPhone Timer

GO also starts a Clock timer through a Shortcut, so it rings even when you leave the app.

Shortcut name (must match exactly)

  1. Open the Shortcuts app → + → name it Rest Timer.
  2. Add action Get Numbers from Input (input: Shortcut Input).
  3. Add action Start Timer, set it to Numbers and unit seconds.
  4. Tap GO once. iOS will ask to allow it, choose Always Allow.
  5. After it starts, tap ◀ Log in the top-left corner to come back.
